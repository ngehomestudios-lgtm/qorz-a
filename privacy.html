Privacy Policy — Qorz-a Studio

Last updated: November 12, 2026

Who uses this tool

Qorz-a Studio is a private tool used only by the owner of the Qorz-a channel, on their own computer. It has no other users.

What data it accesses

  • YouTube (YouTube API Services): uploads videos to the Qorz-a channel, and reads that channel's own video list, view counts and YouTube Analytics reports. It also reads public information about public live streams and videos.
  • TikTok and Instagram (if connected): publishes videos to the Qorz-a accounts and reads those accounts' own basic profile and video statistics.
  • Twitch and Kick: reads public information such as whether a public channel is live and its public video list.

It does not access, collect or store personal data of any other person.

How data is used and stored

Data is used only to publish the channel's videos and to measure their performance. It is stored locally on the owner's computer. It is not sold, shared or transferred to third parties, and it is not used for advertising.

Google / YouTube

This tool uses YouTube API Services. By using it, the user agrees to the YouTube Terms of Service. See also the Google Privacy Policy. Access can be revoked at any time from the Google security settings page.

Deleting data

Revoking access in the account settings of each platform immediately stops all access. Locally stored data can be deleted by the owner at any time. Stored API data is refreshed or deleted within 30 days.

Contact

Questions: contact the Qorz-a channel through its YouTube channel page.
